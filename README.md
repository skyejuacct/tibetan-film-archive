# Tibetan Moving-Image Archive

A static archive site of films about Tibet (1919–1997). All content comes from `data/tibetan-film.xlsx`;
the pages are generated in the browser, so no server or database is needed.

## Updating the site
1. Edit `data/tibetan-film.xlsx` (see the first sheet, 使用说明).
2. On GitHub, open the `data` folder → *Add file → Upload files* → drop the new Excel in → *Commit changes*.
3. Wait about a minute; the published site updates automatically.

Posters / portraits: put `FILM-0001.jpg` (named after the Record ID) in `images/`.
